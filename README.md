# Odoo Apps: Vertical Saas

Odoo modules extending the `vertical` module.

## Usage

Clone this repo into the Odoo addons directory.

```bash
git clone git@github.com:Mint-System/Odoo-Apps-Vertical-Saas.git ./addons/vertical_saas
```
